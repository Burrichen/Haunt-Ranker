Fonts bundled with Haunt Ranker
===============================

Inter     — Copyright (c) 2016 The Inter Project Authors. See inter-OFL.txt.
Fraunces  — Copyright 2018 The Fraunces Project Authors. See fraunces-OFL.txt.

Both are licensed under the SIL Open Font License 1.1, which permits bundling
them with an application provided the licence travels with them — which is why
these files are here.

The .woff2 files are the latin and latin-ext subsets, downloaded from Google
Fonts by scripts/fetch-fonts.mjs. They are shipped with the app rather than
fetched at runtime so that Haunt Ranker looks right offline and makes no
network request of its own.
